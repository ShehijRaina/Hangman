# Hangman

A Hangman game built with **Python** and **PyQt6**, featuring random quotes from the Kaggle [Quotes Dataset](https://www.kaggle.com/datasets/akmittal/quotes-dataset).

## Installation

### 1. Clone the Repository

```bash
git clone https://github.com/ShehijRaina/Hangman.git
cd Hangman
```

### 2. Create a Virtual Environment

```bash
python3 -m venv venv
source venv/bin/activate # On Windows use: venv\Scripts\activate
```

### 3. Install Dependencies

```bash
pip install PyQt6
```

## Running the Game

```bash
python main.py
```
